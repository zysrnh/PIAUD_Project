# PIAUD_Project

Website Resmi Program Studi S1 Pendidikan Islam Anak Usia Dini (PIAUD) - Institut Agama Islam Persis Bandung.

## Tech Stack
- PHP 8.x / Native CMS IAI Persis
- MySQL Database (`iais9713_piaud`)
- Bootstrap, jQuery, Revolution Slider

## Setup Lokal
1. Pastikan Apache & MySQL di Laragon / XAMPP sudah berjalan.
2. Buat database `iais9713_piaud` dan import file `database.sql`.
3. Jalankan web server:
   ```bash
   php -S localhost:8000 router.php
   ```
4. Buka di browser: `http://localhost:8000`
